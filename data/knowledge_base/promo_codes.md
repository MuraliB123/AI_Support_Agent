# Promo Codes & Discounts Policy

**Policy ID:** `PROMO-CODES`  
**Brand:** Nimbus Home

## General Rules

- One promo code per order unless explicitly marked **STACKABLE**
- Promo codes apply to **subtotal before shipping and tax**
- Codes cannot be applied retroactively to completed orders
- Codes have no cash value and cannot be exchanged for gift cards

## Active Code Types

| Code pattern | Discount | Restrictions |
| --- | --- | --- |
| `WELCOME10` | 10% off first order | New customers only; max $50 discount |
| `SHIPFREE` | Free standard shipping | Orders $75+; continental US only |
| `FINAL-SALE` | N/A (item flag) | Item excluded from all other promos |

Seasonal codes (e.g., `SPRING2026`) are announced via email — check marketing calendar in internal wiki before confirming validity.

## Stacking Rules

**Default: no stacking.** If customer applies two codes, only the **higher value** code applies unless one is tagged `STACKABLE`.

`STACKABLE` codes (rare):

- May combine with `SHIPFREE` only
- Never combine with `WELCOME10` or percentage-off codes above 15%

## Expired Codes

If customer reports expired code:

1. Check code end date in promo admin
2. If expired within **48 hours**, agent may issue one-time **5% courtesy code** (`COURTESY5-XXXX`) — max once per customer per 90 days
3. If expired longer, politely decline; offer to subscribe to newsletter for future promos

Do **not** recreate expired campaign codes.

## Price Match

Nimbus Home does **not** price match competitors. Exception: official Nimbus Home sale price drop within **7 days** of purchase — refund difference as store credit (not cash) upon request with proof.

## Employee / Influencer Codes

Codes prefixed `NH-EMP-` or `NH-INF-` are tracked separately. Issues with these codes → escalate to marketing team; do not debug in standard ticket.

## Promo Abuse

Signs of abuse (multiple accounts, reselling, code sharing farms):

- Do not accuse customer in ticket
- Route to `REFUSE-ABUSE` if customer demands repeated courtesy codes or threatens bad reviews for codes
- Route to `ESCALATE-FRAUD` if systematic multi-account pattern suspected
